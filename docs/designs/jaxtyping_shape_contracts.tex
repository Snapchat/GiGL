\section{What changed}

Tensor annotations at stable GiGL boundaries now state dtype, rank, and axis relationships. The annotations remain part of the production API, but runtime checking is enabled only by the unit, integration, and end-to-end test launchers.

\begin{itemize}
  \item \code{jaxtyping} is a runtime dependency because annotations are imported with GiGL modules.
  \item \code{typeguard>=2,<3} is a test dependency and is not installed for production execution.
  \item The launchers install one Jaxtyping import hook for \code{gigl} and \code{examples} before test discovery.
  \item A custom adapter gives Typeguard only annotations that contain a Jaxtyping array type. Existing static-only annotations are not turned into runtime policy.
\end{itemize}

\section{Contract syntax used in GiGL}

Axis names are local to one checked call. Reusing a name across parameters and the return value requires the sizes to match.

\rowcolors{2}{row}{white}
\begin{tabularx}{\linewidth}{@{}>{\ttfamily\small}p{0.43\linewidth}>{\raggedright\arraybackslash}X@{}}
\toprule
\normalfont\bfseries Contract & \bfseries Meaning \\
\midrule
Float[Tensor, "queries embedding\_dim"] & Floating tensor with rank 2 and named axes. \\
Int64[Tensor, "nodes"] & One-dimensional \code{torch.int64} tensor. \\
Float[Tensor, "... feature\_dim"] & Any number of leading axes followed by \code{feature_dim}. \\
Float[Tensor, "\_nodes output\_dim"] & \code{_nodes} is descriptive but does not bind to another annotation. \\
Float[Tensor, "\#batch features"] & \code{batch} may match its bound size or be 1 for broadcasting. \\
Float32[Tensor, "... \{output\_dim\}"] & Final size is read from a runtime argument or instance field. \\
Float[Tensor, ""] & Scalar tensor. \\
\bottomrule
\end{tabularx}
\rowcolors{2}{}{}

Use exact dtypes only where the interface guarantees them. Model and loss boundaries use \code{Float} when mixed precision is valid; ID tensors and packed features use \code{Int64} and \code{UInt8}.

\section{Examples from current GiGL APIs}

The decoder contract ties the input embedding widths together and carries the input counts into the score matrix:

\begin{snippet}
def decode(
    query_embeddings: Float[Tensor, "queries embedding_dim"],
    candidate_embeddings: Float[Tensor, "candidates embedding_dim"],
) -> Float[Tensor, "queries candidates"]: ...
\end{snippet}

Heterogeneous outputs do not require every node type to contain the same number of nodes:

\begin{snippet}
def forward(...) -> dict[
    NodeType, Float[Tensor, "_nodes embedding_dim"]
]: ...
\end{snippet}

Contracts also apply inside containers. This catches a malformed layer output, not merely a malformed list object:

\begin{snippet}
def forward(
    self, xs: list[Float[Tensor, "nodes hidden_dim"]]
) -> Float[Tensor, "nodes output_dim"]: ...
\end{snippet}

\section{Where contracts belong}

Contract tensors crossing loader or sampler interfaces, public model methods, loss and result interfaces, and conversion or quantization boundaries. The dtype, rank, and axis meaning must be stable. Do not annotate internal tensor operations, low-level message passing, or dynamic PyG and TorchRec keyed containers solely for coverage.

\section{Runtime enforcement path}

\begin{tabularx}{\linewidth}{@{}>{\bfseries\color{navy}}p{0.23\linewidth}>{\raggedright\arraybackslash}X@{}}
Test entry points & \code{tests/unit/main.py}, \code{tests/integration/main.py}, and \code{tests/e2e_tests/e2e_test.py} call \code{install_runtime_typechecking()} before importing GiGL modules. \\
Import scope & \code{install_import_hook()} instruments subsequently imported functions and dataclasses in \code{gigl} and \code{examples}. \\
Annotation filter & \code{shape_contract_typechecker()} returns uncontracted functions unchanged. For contracted functions, it creates a private function copy containing only shape-bearing annotations. \\
Runtime check & Typeguard checks arguments before the call and the return value afterward. Jaxtyping binds named axes for that call. \\
Failure & A dtype, rank, or axis mismatch raises \code{jaxtyping.TypeCheckError}; an uncaught error fails the test command. \\
Telemetry & Each process logs whether checking was enabled and how many functions were instrumented. The count is not the number of calls or tensor checks. \\
\end{tabularx}

The private function copy matters because Typeguard reads \code{__annotations__} at call time. The adapter restores the complete public annotation mapping on the wrapped function, so runtime filtering does not change the API seen by introspection or static tooling.

\section{Why Typeguard 2.x instead of Beartype}

Both libraries integrate with Jaxtyping and both were viable. GiGL uses Typeguard for deterministic container coverage.

\rowcolors{2}{row}{white}
\begin{tabularx}{\linewidth}{@{}p{0.25\linewidth}>{\raggedright\arraybackslash}X>{\raggedright\arraybackslash}X@{}}
\toprule
\bfseries Criterion & \bfseries Typeguard 2.x & \bfseries Beartype \\
\midrule
Container checking & Exhaustively checks values reached through annotated containers. & Samples container contents to keep checking near constant time. \\
GiGL impact & Deterministically checks contracts such as \code{list[Float[...]]}, \code{dict[NodeType, Float[...]]}, and nested loader inputs. & A malformed tensor can be missed when its container element is not sampled. \\
Runtime cost & Higher for large containers, accepted because checking runs only in tests. & Lower and more suitable when runtime overhead is the primary constraint. \\
Jaxtyping support & Supported, with the 2.x series required because Jaxtyping documents known issues in Typeguard 3 and 4. & Supported without the Typeguard version constraint. \\
\bottomrule
\end{tabularx}
\rowcolors{2}{}{}

The custom annotation filter is separate from this choice. It prevents either checker from treating all existing GiGL annotations as runtime contracts. TypeVars bounded by non-runtime-checkable Protocols and unresolved forward references can otherwise fail during \code{isinstance} evaluation.

\section{Enforcement boundaries}

\begin{itemize}
  \item Checks run only for calls reached by tests through the standard GiGL test launchers. Commands that bypass those entry points do not install the hook.
  \item The hook affects modules imported after installation; this is why installation precedes test discovery and GiGL imports.
  \item Only annotations containing a Jaxtyping array type are checked. This is not repository-wide runtime validation of ordinary Python annotations.
  \item Axis bindings apply within one checked function call. The same name in separate calls does not create shared state.
  \item A leading underscore makes an axis independent. Use it for heterogeneous dictionary values whose node counts legitimately differ by key.
\end{itemize}
